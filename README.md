# 🌍 POPULENS

**POPULENS** adalah aplikasi dashboard sederhana berbasis **Streamlit** untuk pencatatan dan visualisasi **angka kelahiran dan kematian** berbagai negara di dunia.

Aplikasi ini menggunakan **dataset dari World Bank** untuk menampilkan data demografi secara interaktif dan mudah dipahami.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://gdp-dashboard-template.streamlit.app/)

---

## ✨ Fitur Utama

* Visualisasi angka **kelahiran** dan **kematian** per negara
* Pemilihan negara dan tahun secara interaktif
* Grafik dan tabel yang mudah dibaca
* Dataset resmi dari **World Bank**

---

## 📊 Sumber Data

Data yang digunakan dalam aplikasi ini berasal dari:

* **World Bank Open Data**

  * Birth rate (crude)
  * Death rate (crude)

---

## 🚀 Cara Menjalankan di Komputer Lokal

Ikuti langkah-langkah berikut untuk menjalankan aplikasi POPULENS di mesin Anda sendiri:

### 1. Install dependensi

```bash
pip install -r requirements.txt
```

### 2. Jalankan aplikasi Streamlit

```bash
streamlit run streamlit_app.py
```

Setelah itu, aplikasi akan otomatis terbuka di browser.
